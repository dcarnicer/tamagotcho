Install Tamagotcho

Kanji flashcards with spaced repetition for the M5Stack StickS3, M5Stack Cardputer ADV and LilyGO T-Display-S3. Flash the firmware straight from Chrome or Edge — no download and no esptool.

The combined M5 image is the one M5Burner serves; the board-specific StickS3 and Cardputer ADV images are equivalent. Pick one for your board. The manifest and image links are the manual fallback when JavaScript is unavailable.

Before you start

  1. Chrome or Edge on a desktop. Firefox and Safari do not provide Web Serial, and phones and tablets are not supported here.
  2. A USB data cable. Some cables only charge and never show a serial port. Connect the device directly, without a hub if you can.
  3. Close other serial programs (Arduino IDE, PlatformIO's monitor, another browser tab) so the port is free.
  4. Press Connect, choose the port, then confirm the install. Keep the cable connected until the page says it is done.

On the first boot the firmware formats its storage, asks for the language and the date, and opens the Wi-Fi setup portal. The user guide walks through the first start.

Updates: keep your settings

Do not use this page to update an existing device: it always writes the merged image, so the Wi-Fi settings, preferences and time zone are erased. Get the board's app-only image (tamagotcho-<board>.bin) from the release page and write it at the app offset instead: 

esptool --chip esp32s3 write_flash 0x10000 tamagotcho-sticks3.bin

Use tdisplay-s3, cardputer-adv or m5stack in place of sticks3 for the other images. M5Launcher can install the app-only image too. Decks and study progress survive both paths unless the flash was erased first.

Troubleshooting

  • No port appears: try another USB data cable and reconnect the device. Close any program that may hold the port.
  • The install button is disabled: open the page in a current Chrome or Edge on a desktop, over HTTPS.
  • The device already has Tamagotcho: you can still do a first install this way, but the settings will be erased. To keep them, use the app-only image above.
  • Nothing happens after flashing: unplug and replug the device, then open the page once more. A merged image has no filesystem, so the first boot prepares it.
