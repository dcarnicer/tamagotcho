## What's new

- **A notice when a new firmware is available.** The boot update check now
  ends with a full-screen notice when it finds a newer release: "v0.7.3
  available" and "Settings > Device > Firmware". It stays 4 s or until a
  press, appears once per version (NVS `fwnotified`), and never interrupts a
  quiz. The Device row's gear and the Firmware row keep showing the offer
  until the device runs it. A badge left by Get decks, the portal or the
  network test is announced the same way at the next boot.

- **The M5Burner package is a release asset.** Every release now carries
  `Tamagotcho-<version>.bin` (the merged `m5stack` image at `0x0`, ready for
  the M5Burner Publish dialog) and `tamagotcho-m5burner-<version>.zip` (the
  `m5burner.json` package for the M5Stack-Firmware route), plus
  `SHA256SUMS.txt`. The repository also has `make dist` and `make m5burner`
  to build the same artifacts locally.

All four release environments build and the native tests pass (302 passed,
1 skipped); the release tools' tests pass (22).
