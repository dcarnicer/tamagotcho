## What's new

- **Deck updates are counted from any home-Wi-Fi session.** Joining the home
  network is the slow part, so the update count no longer waits for the
  standalone boot check: Get decks, the portal page, **Wi-Fi > Home network
  (test)** and the boot-time date sync all refresh it from the catalog they
  read. The date sync adds the catalog read only on the days the check is due
  (daily on USB, weekly on battery from 50 %); a read by any session counts as
  that day's check, so the boot check is not repeated. Only the boot check
  shows the result screen; the other sessions update the **Decks** badge
  silently.
- **Update texts that fit.** The boot check's result was cut on the 135 px
  screen in both languages; it now reads "6 updates" / "6 mazos por
  actualizar". The settings home's **Decks** row keeps its badge in portrait
  ("Decks 6 upd", "Mazos 6 act"), and the **Updates** and **Get decks** headers
  show the network and a count ("Shimokitazawa · 6") instead of a cut sentence.

**Updating from v0.5.0:** the app-only image keeps settings, decks and progress
(`write_flash 0x10000 tamagotcho-<board>.bin`). The `m5stack` image on M5Burner
is one entry for the StickS3 and the Cardputer ADV.

**Checked on hardware** (StickS3, 2026-10-23):

- With 8 decks installed and 6 updates, the boot check joined the home network
  in 6.4 s, hashed the decks in 4.3 s and showed "6 mazos por actualizar"; a
  tap during the join skipped it, and an unreachable catalog URL showed
  "Servidor inaccesible" and continued to the quiz.
- With the day's check cleared, the boot-time date sync read the catalog on the
  same connection and showed "6 updates"; a second date sync on the same day
  went straight to the quiz. The portal page load and the network test both
  refreshed the count, and the next reboot did not repeat the check.
- The Spanish and English result lines, the portrait **Decks** badge and the
  shortened headers were seen on the device without ellipsis.

All four release environments build (`sticks3`, `tdisplay-s3`,
`cardputer-adv`, `m5stack`); native tests: 236 passed, 1 skipped. The battery thresholds of
the automatic check are native-tested only; a full discharge run (100 % to 0 %
in about 2 h at full brightness) confirmed the critical-battery sleep.
